## Evidências a anexar
O desafio da DIO solicita prints ou pequenos vídeos das interações com IA. Para garantir autenticidade, inclua **capturas reais**; nenhuma imagem foi inventada para esta entrega.

| Evidência | O que mostrar | Status |
| --- | --- | --- |
| Interação com IA | Trecho do prompt de definição do RECOMEÇO | Pendente de captura |

| Interface | Dashboard ou tela inicial publicada | Pendente de captura |

## Como adicionar
1. Crie a pasta `assets/screenshots/` no repositório.
2. Faça prints das interações e telas, ocultando nomes, valores reais, tokens e identificadores sensíveis.
3. Envie os arquivos ao GitHub.
4. Substitua abaixo os exemplos apenas pelos nomes dos arquivos existentes:

```md
![Prompt de especificação](../assets/screenshots/prompt-recomeco.png)
![Tela inicial](../assets/screenshots/tela-inicial.png)
![Fluxo financeiro](../assets/screenshots/fluxo-financeiro.png)
```

## Roteiro de apresentação (60–90 segundos)
- **Problema:** controlar finanças é especialmente difícil com dívidas e renda apertada.
- **Ideia:** RECOMEÇO une visão financeira e planejamento para o próximo passo.
- **Metodologia:** PRD e refinamento de prompts com apoio de IA.
- **Diferencial:** recuperação financeira acolhedora e projeções explicáveis.
- **Demonstração:** mostrar apenas funcionalidades realmente presentes no aplicativo.
- **Aprendizado:** prompts claros, testes e critérios de aceite são parte essencial do Vibe Coding.

## Cuidados
Não publique extratos, números pessoais de contas, dívidas reais, documentos pessoais ou senhas. Use dados fictícios e peça autorização antes de mostrar imagens de terceiros.
